# Test map
- `apps/web/npm test` and `npm run build` validate the application contract.
- Docs sync, schema, translation, link, and three-language builds validate aggregation.
- Legal review and live child pilots cannot be replaced by synthetic tests.
- `apps/web/tests/webmcp-platform.test.mjs` verifies the twelve-tool catalog, minimal MV3 permissions, theme provenance, deterministic fixtures, score threshold, and absolute barriers.
- `node tools/webmcp_evidence_gate.mjs --require-b-plus` writes local reports; it records Chrome and Edge discovery as not run.
