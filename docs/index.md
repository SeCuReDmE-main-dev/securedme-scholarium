## Documentation contract

This portal is an orientation and learning surface. The README, contribution guide, security policy, safety boundary, and license inside each repository remain authoritative for that tool. Generated simulations and agent output remain reviewable artifacts; they are not scientific, legal, clinical, security, or editorial authority.

!!! tip "Fast daily use"
    Search first. Open one tool guide. Select one collaboration prompt. Verify the evidence. Keep the final decision human.
