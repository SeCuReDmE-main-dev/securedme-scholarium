# Interfaces

- **React algorithm canvas:** use only through the documented repository route.
- **Algorithm palette:** use only through the documented repository route.
- **Properties and explanation panels:** use only through the documented repository route.
- **Backend service:** use only through the documented repository route.

## Interface contract

Inputs must be explicit, outputs must be inspectable, errors must be returned as errors, and consequential external actions require human approval.

## Compatibility

Treat undocumented endpoints, commands, and browser controls as unsupported. Confirm the current repository version before integrating another system.
