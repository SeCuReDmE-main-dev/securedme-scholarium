# AlgoQuest Qbit Education quickstart

## Requirements

Use a clean checkout, the runtime declared by the repository, and its committed lockfiles. Confirm the active branch before installing anything.

```powershell
git status --short --branch
```

## Install

```powershell
npm install
```

## Start

```powershell
npm run dev
```

## Verify

```powershell
npm test
```

## Human acceptance

Inspect the output, logs, test results, and diff. Accept, request a correction, quarantine, or stop; do not silently promote a generated result.

`npm test` includes the v1 compatibility and Mage v2 contract checks, TypeScript, MkDocs, accessibility, browser behavior, and deterministic 1/25/100 replay gates. It does not substitute for live extension, identity, Colab, or school acceptance.
