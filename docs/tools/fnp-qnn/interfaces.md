# Interfaces

- **fnp-qnn CLI:** use only through the documented repository route.
- **fnp-qnn TUI:** use only through the documented repository route.
- **FastAPI simulator service:** use only through the documented repository route.
- **Local operator panel:** use only through the documented repository route.

## Interface contract

Inputs must be explicit, outputs must be inspectable, errors must be returned as errors, and consequential external actions require human approval.

## Compatibility

Treat undocumented endpoints, commands, and browser controls as unsupported. Confirm the current repository version before integrating another system.
