# CP-10 - Evaluate candidate admissibility

**Tool:** `ffed-qlc`

## English

**Objective.** Evaluate candidate admissibility

```text
TOOL: ffed-qlc

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Run one candidate through declared FfeD-QLC criteria without promoting it to proof.

REQUIRED OUTPUT
An admitted, suspended, or rejected trace with reasons.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
