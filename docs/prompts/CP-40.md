# CP-40 - Publish portfolio evidence

**Tool:** `scholarium`

## English

**Objective.** Publish portfolio evidence

```text
TOOL: scholarium

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Convert validated work into a concise public claim linked to the artifact and its limits.

REQUIRED OUTPUT
A declarative portfolio entry with direct proof links.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
