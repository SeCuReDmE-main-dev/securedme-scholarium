# CP-35 - Place a human approval gate

**Tool:** `scholarium`

## English

**Objective.** Place a human approval gate

```text
TOOL: scholarium

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Identify the consequential action, required evidence, authorized reviewer, and refusal path.

REQUIRED OUTPUT
An approval contract that defaults to no action.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
