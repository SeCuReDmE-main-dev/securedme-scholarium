# CP-05 - Audit a public route

**Tool:** `scholarium`

## English

**Objective.** Audit a public route

```text
TOOL: scholarium

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Check availability, title, primary action, documentation link, and mobile behavior.

REQUIRED OUTPUT
A pass/fail route report with screenshots or response evidence.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
