# CP-06 - Design a bounded learner challenge

**Tool:** `algoquest-qbit`

## English

**Objective.** Design a bounded learner challenge

```text
TOOL: algoquest-qbit

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Create one challenge with objective, hints, observable success, and teacher review.

REQUIRED OUTPUT
A challenge specification and acceptance rubric.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
