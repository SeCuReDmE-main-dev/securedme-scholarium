# CP-04 - Plan one bounded change

**Tool:** `scholarium`

## English

**Objective.** Plan one bounded change

```text
TOOL: scholarium

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Turn a requested outcome into scope, files, risks, checks, and stop points.

REQUIRED OUTPUT
A decision-complete plan that does not execute the change.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```

## Francais

**Objectif.** Planifier un changement borne

```text
TOOL: scholarium

ENTREES REQUISES
Fournir le depot ou l'artefact, l'objectif exact, les contraintes et les preuves deja disponibles.

TRAVAIL BORNE
Transformer le resultat demande en perimetre, fichiers, risques, tests et arrets.

SORTIE OBLIGATOIRE
Un plan complet qui n'execute pas le changement.

VALIDATION
Retourner COMPLETED, NEEDS_INPUT, QUARANTINED ou BLOCKED. Citer fichiers, commandes, URL et resultats observes.

HUMAN STOP
Arreter avant publication, depense, suppression, changement distant, exposition de secret ou promotion d'une affirmation non verifiee.
```

## Espanol

**Objetivo.** Planificar un cambio acotado

```text
TOOL: scholarium

ENTRADAS REQUERIDAS
Proporcionar el repositorio o artefacto, objetivo exacto, restricciones y evidencia disponible.

TRABAJO ACOTADO
Convertir el resultado pedido en alcance, archivos, riesgos, pruebas y paradas.

SALIDA OBLIGATORIA
Un plan completo que no ejecuta el cambio.

VALIDACION
Devolver COMPLETED, NEEDS_INPUT, QUARANTINED o BLOCKED. Citar archivos, comandos, URL y resultados observados.

HUMAN STOP
Detenerse antes de publicar, gastar, borrar, cambiar estado remoto, exponer secretos o promover afirmaciones no verificadas.
```
