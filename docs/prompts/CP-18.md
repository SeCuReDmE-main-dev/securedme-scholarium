# CP-18 - Audit defensive evidence

**Tool:** `retailguard`

## English

**Objective.** Audit defensive evidence

```text
TOOL: retailguard

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Check provenance, alternative explanations, uncertainty, and escalation criteria.

REQUIRED OUTPUT
An evidence table that does not accuse a person.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
