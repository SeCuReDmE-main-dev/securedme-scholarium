# CP-17 - Build a defensive retail scenario

**Tool:** `retailguard`

## English

**Objective.** Build a defensive retail scenario

```text
TOOL: retailguard

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Create a synthetic prevention scenario with no operational attack instructions.

REQUIRED OUTPUT
A supervised scenario, safeguards, and debrief questions.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
