# CP-29 - Review a defensive threat signal

**Tool:** `vot-guardian`

## English

**Objective.** Review a defensive threat signal

```text
TOOL: vot-guardian

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Assess a synthetic signal using provenance, alternatives, confidence, and human escalation.

REQUIRED OUTPUT
A defensive review that makes no autonomous accusation.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
