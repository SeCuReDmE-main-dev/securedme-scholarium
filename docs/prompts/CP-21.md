# CP-21 - Use HippoRAG as evidence support

**Tool:** `quanthor`

## English

**Objective.** Use HippoRAG as evidence support

```text
TOOL: quanthor

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Retrieve relevant source paths and keep retrieval separate from formal validity.

REQUIRED OUTPUT
A cited retrieval trace and independent proof obligations.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
