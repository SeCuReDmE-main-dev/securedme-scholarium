# CP-07 - Review a teacher pathway

**Tool:** `algoquest-qbit`

## English

**Objective.** Review a teacher pathway

```text
TOOL: algoquest-qbit

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Inspect pacing, prerequisites, learner choices, and feedback without grading automatically.

REQUIRED OUTPUT
A revised pathway with explicit teacher decisions.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
