# CP-15 - Validate a gateway command

**Tool:** `fnpqnn-gateway`

## English

**Objective.** Validate a gateway command

```text
TOOL: fnpqnn-gateway

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Check command inputs, schema, error behavior, output, and replay path.

REQUIRED OUTPUT
A command contract with one positive and one negative case.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
