# CP-30 - Explain a security decision

**Tool:** `vot-guardian`

## English

**Objective.** Explain a security decision

```text
TOOL: vot-guardian

REQUIRED INPUTS
Provide the repository or artifact, exact goal, constraints, and evidence already available.

BOUNDED WORK
Translate a decision trace into evidence, uncertainty, rejected alternatives, and operator action.

REQUIRED OUTPUT
A concise explanation suitable for supervised training.

VALIDATION
Return COMPLETED, NEEDS_INPUT, QUARANTINED, or BLOCKED. Cite files, commands, URLs, and observed results.

HUMAN STOP
Stop before publishing, spending, deleting, changing remote state, exposing a secret, or promoting an unverified claim.
```
