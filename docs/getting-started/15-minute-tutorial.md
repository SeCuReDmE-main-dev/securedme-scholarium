# Start with SeCuReDmE Education in 15 minutes

This route teaches the shared operating method. It does not pretend that all twelve tools have the same runtime.

## Minutes 0-3: choose a real surface

Open the [tool library](../tools/index.md). Select a browser application for an interactive lesson, or a local, CLI, API, or research surface for inspectable execution. Read the status and boundary before starting.

## Minutes 3-7: inspect before installing

Open the selected tool's quickstart and source repository. In a clean checkout, record the active branch and changes:

```powershell
git status --short --branch
```

Use only the installation command committed by that tool. Never paste a password, cookie, private token, or `.env` value into a prompt or tutorial.

## Minutes 7-12: run one bounded action

Execute the smallest documented example. Keep the input, command, output path, and test result together. A generated file, screenshot, or model answer is a candidate artifact until the documented validation succeeds.

## Minutes 12-15: review and decide

Inspect the result and choose `COMPLETED`, `NEEDS_INPUT`, `QUARANTINED`, or `BLOCKED`. Stop before publishing, spending, deleting, changing remote state, or promoting an unverified scientific or educational claim.
